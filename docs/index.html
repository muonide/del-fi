WHAT IS THIS 
Drop documents into a folder. Connect a $30 radio. Your neighborhood now has an AI oracle -- no internet, no cloud, no accounts.

A Del-Fi node is a Meshtastic radio plus a small computer. When someone sends it a DM, Del-Fi finds the relevant passages in your docs, asks a local LLM, and replies within the 230-byte LoRa limit -- everything on your hardware. With gossip on, nodes point people to each other, so every node added makes the whole net more useful.

Have a script write sensor readings to a JSON feed and the FactStore answers measurement questions directly -- no LLM, no made-up numbers.

Drop documents into knowledge/, run --build-wiki once, and the LLM compiles them into a wiki: a page per document, with titles and tags. At question time the wiki finds the right documents, and only their most relevant sections go to the model -- so even a 1B model gets short, focused context. Edit a document and the running node recompiles its page.

One Python package. Three core dependencies. Runs fully offline.

HARDWARE

  Raspberry Pi 5 8GB .... ~$80            Any Meshtastic
  Jetson Orin Nano ...... ~$249           LoRa radio.
  Mac Mini M4 ........... ~$499           Heltec V3 is ~$20.

  On a Pi, start with a 1B model;         Antenna placement matters
  bigger ones answer better, slower.      more than radio choice.
  --bench times them on your hardware.
QUICK START 
  $ curl -fsSL https://ollama.com/install.sh | sh
  $ ollama pull gemma4:e4b && ollama pull nomic-embed-text
  $ git clone https://github.com/geodesic-glitch/del-fi.git && cd del-fi
  $ python3 -m venv venv && . venv/bin/activate
  $ pip install -r requirements.txt
  $ cp config.example.yaml config.yaml  # set node_name and model
  $ python main.py --build-wiki  # compile knowledge/ → wiki/
  $ python main.py

  Edit config.yaml to set node_name, model, and personality.
  Drop .md or .txt files into knowledge/ and re-run --build-wiki.
  Everything else has sensible defaults.

  No radio? Test with:  python main.py --simulator
  Time the answers:     python main.py --bench

 USE CASES

Trail Oracle
Solar node at a trailhead. Plant ID, trail conditions, emergency procedures.
Farm Oracle
Planting calendars, livestock medicine, equipment repair for the whole property.
Emergency Response
Triage protocols, shelter locations, phrase books. Works when towers don't.
The Dead Drop
Mysterious node appears on mesh. Cryptic name, oddly specific local knowledge.
Festival Concierge
Schedules, vendor maps, food guides. No cell service required.
Neighborhood Mesh
HOA rules, garbage day, business hours. "When's bulk trash pickup?"
SAMPLE SESSION 
── SALMONBERRY CREEK PRESERVE · node: DAWN-CHORUS ───────────────────

you>  what's singing right now?
node> DAWN-CHORUS: Singing Now: Pacific Wren 7:44, Song Sparrow 7:43, Chestnut-backed Chickadee 7:43, Spotted Towhee 7:42, Red-breasted Nuthatch 7:41, Black-capped Chickadee 7:40 (birdnet-pi, 1m ago)

you>  I heard a bird that goes fee-bee
node> That's a Black-capped Chickadee: a clear two-note whistle, the second note lower. Males sing it from January on. Whistle it back and one may answer.
      ---
      DAWN-CHORUS: birds of Salmonberry Creek. !data = live detections

you>  something is making a long eerie whistle in the cedars
node> Likely a Varied Thrush: one long, buzzy whistle on a single pitch, then a pause and another on a new pitch. The first of the autumn was heard on the Cedar Trail on Sep 23.

you>  any owls tonight?
node> DAWN-CHORUS: Owls Tonight: since 18:00: Barred Owl (3), Western Screech-Owl (1); last at 4:12 (birdnet-pi, 1m ago)

you>  big woodpecker on a dead tree, what is it?
node> Could be a Pileated Woodpecker or a Northern Flicker. Pileated is crow-sized and black with a red crest; a flicker is brown with a spotted belly. Which was it?

you>  black with a red crest
node> Black with a red crest: that's a Pileated Woodpecker, the biggest woodpecker here. A pair has been chopping a big new hole by Cedar Trail footbridge 2 this month.

Live answers come straight from a BirdNET-Pi listening station.
Identifications come from the knowledge base via the local LLM.

ARCHITECTURE 
[LoRa Radio] <--serial/tcp--> [Mesh Adapter] <--> [Dispatcher] <--> [Router]
                                     |               |               |
                              (meshtastic)   rate limit,     Tier 0  FactStore   sensor feed, no LLM
                                             queue           Tier 1  WikiEngine  wiki search + best source passages
                                                           Tier 2  PeerCache   trusted peer Q&A
                                                           Tier 3  GossipDir   referrals only

main.py ................. entry point: daemon, --simulator, --build-wiki, --lint-wiki, --bench, --gui
del_fi/
  config.py ............. YAML loading, validation, oracle profiles
  bench.py .............. --bench: time answers to a list of questions
  core/
    dispatcher.py ........ main loop: rate limit, question queue, worker thread
    knowledge.py ......... WikiEngine: compile knowledge/ → wiki/, passage retrieval, lint
      knowledge/ .......... raw source docs (human-owned, gitignored)
      wiki/ ............... LLM-compiled pages, rebuilt via --build-wiki
    router.py ........... command dispatch, tier routing, !more buffer
    formatter.py ........ 230-byte enforcement, UTF-8 safety, chunking
    facts.py ............ FactStore: sensor feed, Tier 0 fast path
      cache/sensor_feed.json  external scripts write readings here
    peers.py ............ PeerCache (Tier 2) + GossipDirectory (Tier 3)
    memory.py ........... per-sender conversation history, TTL
    board.py ............ community message board, !post / !board
  mesh/
    base.py ............. abstract MeshAdapter interface
    meshtastic_adapter.py  Meshtastic radios (serial/TCP/BLE), auto-reconnect
    meshcore_adapter.py    MeshCore radios (stub -- not functional yet)
    simulator.py ........ stdin/stdout for development
